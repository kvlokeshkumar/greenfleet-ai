# Data and Model Files

All datasets in this project are synthetic and generated by scripts in this repository with fixed seeds (42). Every data and model file is under 10 MB, so all of them live in plain Git. Git LFS and external storage are not used. Cloning the repository is enough; no download step is needed.

## Files in Git

| File | Size | Rows x Cols | Produced by | Purpose |
|---|---|---|---|---|
| `ml_engine/data/raw/fleet_data.csv` | ~0.6 MB | 6000 x 18 | `python ml_engine/generate_data.py` | Trip-level training data for Model 1 (target `fuel_consumed_l`) |
| `ml_engine/data/processed/processed_fleet_data.csv` | ~1.1 MB | 6000 x 24 | `python ml_engine/train.py` | Raw trips plus engineered features |
| `ml_engine/data/raw/synthetic_telemetry.csv` | ~1.0 MB | 5760 x 26 | `python ml_engine/simulation/generate_telemetry.py` | 1 Hz driving telemetry for Model 2 (target `fuel_consumption_l_100km`) |
| `ml_engine/data/processed/processed_telemetry.csv` | ~1.4 MB | 5760 x 31 | `python ml_engine/training/train_fuel_model.py` | Telemetry plus engineered features |
| `ml_engine/models/fuel_model.pkl` | ~0.8 MB | — | `python ml_engine/train.py` | Model 1: trip fuel regressor (LightGBM pipeline) |
| `ml_engine/models/evaluation_metrics.json` | small | — | `python ml_engine/train.py` | Model 1 metrics for all candidate models |
| `ml_engine/models/telemetry_fuel_model.pkl` | ~6.8 MB | — | `python ml_engine/training/train_fuel_model.py` | Model 2: telemetry fuel-rate regressor (Random Forest pipeline) |
| `ml_engine/models/telemetry_evaluation_metrics.json` | small | — | `python ml_engine/training/train_fuel_model.py` | Model 2 metrics |
| `ml_engine/models/*.png` | <0.4 MB each | — | `python ml_engine/evaluate.py` | Actual vs predicted, feature importance and residual plots for Model 1 |
| `backend/app/data/sample_routes.json` | small | 47 lines | hand-written | Seed for the in-memory `/api/fleet/routes` list |
| `backend/app/data/sample_vehicles.json` | small | 47 lines | hand-written | Sample vehicles (not read by the current registry) |

The 20-vehicle demo fleet and 12 demo routes used by the simulation are defined in code in `simulation/dataset.py`.

## Not in Git

| Item | What it is | How to get it back |
|---|---|---|
| `greenfleet.db` | SQLite file holding the vehicle registry and driver-behaviour samples | Created automatically when the backend starts and seeded with the 20 demo vehicles. Back it up separately only if you need vehicles registered through the UI. |
| `.venv/` | Python virtual environment | `pip install -r requirements.txt -r backend/requirements.txt -r ml_engine/requirements.txt` |
| `frontend/node_modules/` | npm packages | `cd frontend && npm install` |

## Regenerating everything

Run from the repository root with the virtual environment active:

```bash
python ml_engine/generate_data.py
python ml_engine/train.py
python ml_engine/evaluate.py
python ml_engine/simulation/generate_telemetry.py
python ml_engine/training/train_fuel_model.py
```

Each script uses seed 42 by default. Results should be close to the committed metrics, but exact values can differ between library versions. The committed `telemetry_fuel_model.pkl` was saved with scikit-learn 1.8.0, so retrain it if you see an `InconsistentVersionWarning` on a newer version.

Column meanings and preprocessing steps are documented in `PROJECT_KNOWLEDGE.txt`, section 5.
